### Jewelry Store — iOS Developer

**Swift, SwiftUI, SwiftData, Firebase, UIKit, MVVM, REST API, Node.js, WidgetKit, APNs**

Разработал полноценное iOS-приложение интернет-магазина ювелирных изделий с нуля. Реализовал каталог товаров с фильтрацией, авторизацию и регистрацию, избранное, корзину, настройки приложения и систему уведомлений.

Архитектура построена на **MVVM + Service Layer** с использованием современного `@Observable` и Dependency Injection через `EnvironmentValues`. Для локального хранения данных использовал **SwiftData**, для авторизации и облачной инфраструктуры — **Firebase**.

Реализовал **Face ID** с автоматической блокировкой приложения при запуске и после длительного нахождения в фоне. Интегрировал **APNs** для push-уведомлений и разработал собственный Notification Center с историей уведомлений, отметкой о прочтении, удалением и Deep Link-навигацией.

Разработал **WidgetKit Extension** с синхронизацией данных между приложением и виджетом через **App Groups** и `UserDefaults(suiteName:)`.

Создал backend на **Node.js + Express** для системы поддержки пользователей. Реализовал REST API и интеграцию с **Telegram Bot API**, позволяющую отправлять обращения из iOS-приложения непосредственно в Telegram.

Проект демонстрирует практический опыт разработки iOS-приложений полного цикла: **SwiftUI → архитектура → локальное/облачное хранение → авторизация → системные API Apple → push-уведомления → WidgetKit → REST API → Node.js backend**.
